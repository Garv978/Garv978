# 🚀 Featured Project

## 🖨️ EasyPrint

A full-stack platform designed to connect users with local printing shops and simplify the process of submitting and managing print jobs.

### What I'm working with

* 🔐 Authentication & role-based access
* 👤 Separate user and shop-owner workflows
* 📄 File uploads & PDF processing
* 🖨️ Print-job management
* 💰 Dynamic print-price calculation
* ⚡ REST APIs with Node.js & Express
* 🗄️ MongoDB data modeling
* 🔄 Real-time job/status communication
* 🐳 Docker & deployment
* 🔍 CI/CD and code-quality checks
* 🛡️ Production-focused validation and error handling

The project has pushed me beyond simply building features and into understanding **application architecture, debugging, security, deployment, and production code quality**.
